ASTROBIO — Project Overview

ASTROBIO is a simulation prototype for explainable health monitoring during space missions. It is not a medical device, diagnostic tool or clinically validated scoring system.

Interface and server

The application includes mission dashboards, daily indicator demos, measurements, BIS / Cole model visualizations, an interactive anatomical map, local AI chat and delayed ground-team reports. Authenticated server findings and check-in forms are available in Interactive Health Check. Visual ring scores and BIS charts are separate synthetic design examples.

Local AI and voice

Medical rules remain authoritative. The optional communication model cannot rewrite canonical medical facts. Microphone recording, transcript confirmation and speech playback require explicit user actions. Voice dependencies and models are installed separately with license approval.

Data and privacy

Server access is role-filtered: crew members see their own records, the crew medical officer sees authorized crew records, and ground staff see delivered messages. Example JSON imports and design calendar notes remain in browser storage; do not use real patient data.

Attribution and limitations

RIDGE categories follow NASA spaceflight hazard concepts. The optional 3D viewer references Open Anatomy 3D, BodyParts3D / DBCLS, HuBMAP and MakeHuman. Verify the license and attribution of any downloaded model. Real-world clinical, microphone and WebGL validation remains outside this prototype.
